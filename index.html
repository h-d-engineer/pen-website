OpenEMT

The electromagnetic transient simulator built for AI agents.

One deterministic solver core with three ways in: a drag and drop canvas that runs in the browser with no install, a command line for scripts, and an MCP server that lets an AI agent build a circuit, run it, and read the results.

Solver
EMTP-style trapezoidal nodal analysis with power flow
Catalog
36 blocks: lines, transformers, machines, converters, protection
Status
Public beta, AGPL-3.0

Hawraman Chronicles

A terraced village builder and survival game set in the mountains of Hawraman.

Build a stepped mountain village, prepare for hard winters, and walk through the region's history in a story mode. Hawraman is a UNESCO World Heritage cultural landscape, and the game is shaped by first-hand local knowledge. Every piece of art is drawn in code.

What we do

We go where the problem goes.

The sample projects above cover two fields. The capabilities behind them are broader, and the list below is a starting point, not a boundary.

Software products

Web, mobile, and desktop applications, taken from a first sketch to a released product that people actually use.

AI and agents

Tools designed for AI agents as much as for people: agent interfaces, automated workflows, and software that agents can drive end to end.

Simulation and modeling

Numerical solvers and working models of real systems, checked against known answers, so a question can be tested before it is built.

Games and learning

Games and interactive experiences that teach by letting people live inside a subject, researched with care and respectful of the culture they portray.

Engineering consulting

Technical studies and analysis led by a licensed Professional Engineer. Power systems is the home discipline, not the limit.

Research and prototypes

A new idea with no clear path yet: we find out whether it works by building a prototype and measuring it.
